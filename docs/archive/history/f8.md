# F8 — One visual language for pcom (done 2026-10-04, branch `feat/f8-design`, #209)

**Built.** pcom's own design system replaces Bootstrap and bootstrap-icons. The design was approved on a
Claude Design canvas first: Paper colors (warm paper light theme, warm brown-black dark theme, olive and
sage accents) and Golos Text, chosen because posts are written in Russian and the face needs Cyrillic.
`_tokens.scss` holds the light and dark tokens and the font faces: Golos Text 400/600/800, self-hosted,
split by `unicode-range` into latin, latin-ext, cyrillic and cyrillic-ext, with a metric-matched Arial
fallback. Latin and Cyrillic 400/800 are preloaded from `header.html`. `_base.scss` holds the base styles,
and `_components.scss` the buttons, fields, meta, item actions, boxes, status, nav, toasts and the editor
toolbar. There is one partial per area. Every page moved onto it:
- **Header:** Write is the main button, the username opens settings, there is a phone menu, and the GitHub
  link is in the footer.
- **Toasts:** pcom's own markup with a real close button.
- **Editor toolbar:** real buttons with labels and inline SVG.
- **Content:** feed, journal, explore, index, single post and comments are not boxed and have one row of
  text actions. The spoiler is a real button with `aria-expanded`, and standalone images carry pcom
  classes (goldens updated).
- **Settings:** every form and action saves in place and reports next to its button. That includes
  generating an API key, making a new private feed URL and removing a feed, which used to reload the page.
  RSS fetch failures and never-fetched feeds are shown.
- **Other pages:** editor, auth, invite, controls and articles use the same components.

Production CSS went from 49 KB to 6.7 KB gzipped; JS stays 45.5 KB. `TestFirstVisitWeight` enforces the
budgets (CSS 25 KB, fonts 70 KB per page, JS 50 KB). `TestTemplatesAndControllersUseNoBootstrapClasses`
and `TestTemplatesKeepUserStyleHooks` guard the rest. `make test-ui`, which CI's browser job also runs, now
builds production assets.

**Wrong or surprising.**
- **Font URLs in production:** fonts were referenced at `/fonts/...` while the app serves `dist` only under
  `/static/`, so in production they 404ed (the Bootstrap icon font already did). The CSS now points at
  fonts with a relative path.
- **Shared markup broke other tasks' tests:** T1's header change broke 13 tests in files other tasks owned,
  through `navbar` strings, the GitHub link, the "Hi <user>" greeting and the username link. Two of the
  checks became vacuous `NotContains`.
- **Wrong handler file:** the plan put the settings actions in `routes_settings.go`, but they live in
  `actions_settings.go` and `actions_rss.go`, so T3 came back blocked once.
- **Clipboard regression at merge:** T2 made the clipboard controller resolve every value against the
  origin (for share links), which broke copying the API key in T3's tests. Each task passed alone; only
  the merged suite caught it.
- **Weight test measured the wrong build:** T6 first measured the development build, which led to a
  250 KB JS budget that catches nothing.
- **A contradiction in the plan:** it banned the class `btn` while also naming pcom's own button `.btn`. The
  ban list now covers only Bootstrap-specific names.
- **Weak tests found by the audit:** two settings tests never checked stored state, one repeated two
  others, and one waits for the poller.
- **Process slips:** one subagent ran `git stash`/`pop` despite the no-git rule, without damage.

**Left out.** The project website keeps its own stylesheet. There is no pixel diffing of screenshots.
`TestSettings_FeedFetchStates` still waits up to 25 s for the RSS poller, because the factory can't seed
a failed fetch (#211). The header has no link to one's own journal; the owner was asked and has not
decided.

**Decisions.** The owner decided on the canvas: Paper colors, Golos Text plus the system monospace,
Bootstrap dropped, `us-*` hooks stable, the website out of scope, and the speed budget. The coordinator
decided:
- Components use their final names alongside Bootstrap during the wave, with no prefix; pages looked mixed
  until T6.
- Where the canvas and the plan differed, the plan won: buttons weight 600 (the canvas has 500).
- The clipboard controller resolves only paths (`/…`) against the origin.
- `make test-ui` builds production assets, so the browser suite and the weight test see what ships.

**Docs changed.** `docs/product.md`: the `us-*` contract, the username opening settings, and a new
Interface section (forms save in place, toasts only for formless actions, the first-visit budget).
`docs/implementation-plan.md`, Planning a wave: name the handler's real file, and a task that changes shared
markup owns the tests that select it. `wave-run`: worktree `node_modules`, the full suite after merging
parallel tasks, and copying private design references into the scratchpad. `frontend-htmx`: "Design system"
replaces the Bootstrap and dark-mode sections. `docs/testing.md`: `make test-ui` builds production
assets. `AGENTS.md`: the stack line. Guide: settings (the `us-*` table), comments, writing, all seven
screenshots.

**Cost.**
- **Coordinator:** 1 session, 143 turns, peak 275k context, 271k of tool results; flags: `cat`×5.
- **Subagents:** 10. T0 strong, resumed once for the font URLs. T1 mid, resumed once for the broken tests.
  T2–T5 in parallel worktrees (T3 strong; T2 and T3 resumed for follow-ups and audit fixes). T6 mid,
  resumed once for the production build. T7 mid (the plan said cheap; the guide prose has no test). Plus 2
  strong read-only agents: the T3 assertion audit and the docs fact-check.
- **Expensive agents:** two subagents, the feed/post and settings pages, account for 1.5 MB of the 2.2 MB of
  tool results (72 and 105 turns), much of it whole-file reads of the canvas boards and templates.
  Subagents made 54 `cat` calls despite the preamble's rule.
- **Skills:** wave-run×1, wave-close×1, frontend-htmx×5 (its users ran longer, 43 vs 20 median turns,
  because they were the page tasks).
- **Compared with F6** (78 turns, peak 169k): about twice the coordinator turns and context, for a wave
  that touched every template.
