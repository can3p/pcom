## R3 — gogo convergence (planned)

pcom moves onto gogo **v0.1.0**, which breaks gogo's API on purpose to
drop what pcom had outgrown. The gogo side is done (branch
`feat/r3-convergence` in can3p/gogo, to be released as `v0.1.0`):

- `settings` (new): `settings.Parse(p, args)` wraps go-flags' `ParseArgs`.
  A required setting whose value is empty (an environment variable that
  exists but is empty) counts as missing, and the error names every
  missing setting by flag and variable, before any command runs.
  `settings.Secret` redacts itself in `fmt`, `slog` and JSON; `Reveal()`
  returns the value. **R2 uses these; R3 doesn't.**
- `sender.Sender` is `Send(ctx, mail)`: no executor, unique ID or email
  type. Queueing mail in a transaction is the application's job.
- `sender/mailjet`: `config.Config` gains `BaseURL` (`--api-base`,
  `API_BASE`; the host root, such as tommy's `http://localhost:8822`, and
  gogo appends the SDK's `/v3`). The private key is a `settings.Secret`.
  `mailjet.NewSender()` and `mailjet.RequiredEnv` are gone; use
  `NewSenderFromConfig`.
- `forms`: `Validate(c *gin.Context) error`, `Save(ctx) (FormSaveAction,
  error)`, `FormBase.Save(ctx)`, and `DefaultHandler(c, form)`, which opens
  no transaction.
- `apperr` (new): `ErrNotFound`, `ErrForbidden`, `ErrNeedsLogin`,
  `ErrConflict`, `ValidationError`, `Invalid`: pcom's `pkg/service`
  errors, moved.
- `util/ginhelpers`: pcom's `render.go`, moved. `Status`, `HTML`,
  `HTMLError`, `API`; instead of `util.InCluster` and `auth`, a router
  installs `ginhelpers.Configure(ginhelpers.Options{RedirectToLogin,
  ShowErrors})`. Without it, errors are hidden and a page that needs a
  login answers 401. There is no `ErrBadRequest`; nothing in pcom
  returns it outside `render.go`.
- `util/ginhelpers/csrf`: `CSRFMiddleware(func(*gin.Context) string)`,
  comparing in constant time.
- `util.InCluster` is gone from gogo. pcom keeps its own `pkg/util`
  copy until R2 replaces it with explicit settings.

**Behavior doesn't change.** Production still hides error text and
development shows it, `ErrNeedsLogin` still redirects pages to the login,
and every status is the same.

**Before dispatch (coordinator):** merge the gogo PR and tag `v0.1.0`
(the owner's call), then on the wave branch `go get
github.com/can3p/gogo@v0.1.0 && go mod tidy`. The tree stops compiling
there; G1 to G3 make it compile again, **in order** (G2's packages import
G1's, and G2 and G3 both edit the `routes_*.go` files). Run them one at a

### G1

Mail delivery through gogo's new `sender.Sender`, `Send(ctx, mail)`.

- The old interface, `Send(ctx, exec boil.ContextExecutor, uniqueID,
  emailType string, mail *sender.Mail) error`, becomes pcom's own:
  `repo.MailQueue`, declared in `pkg/repo/mail_queue.go` next to
  `Store.SendMail`, which takes it instead of a `sender.Sender`. Its doc
  says what it is: it stores the mail on the caller's executor, so the
  mail goes out only if the transaction commits.
- `dbsender` implements `repo.MailQueue` (its `Send` is unchanged) and
  holds a gogo `sender.Sender` for delivery; the poller calls
  `realSender.Send(ctx, &payload)`.
- `fakesender.Sender` implements `repo.MailQueue` (compile-time check and
  package doc updated); its recording is unchanged, so no test that reads
  `Sent()` changes.
- The services, `registry.Services` and `app.Deps` hold a
  `repo.MailQueue` where they held a `sender.Sender`.
- `cmd/web/main.go` builds the Mailjet sender with
  `mailjet.NewSenderFromConfig(&config.Config{ApiKeyPublic:
  os.Getenv("MJ_APIKEY_PUBLIC"), ApiKeyPrivate:
  settings.Secret(os.Getenv("MJ_APIKEY_PRIVATE"))})` and checks the two
  variables with its own `enforceEnvVars`, in place of
  `mailjet.RequiredEnv`. No new variable is read: `BaseURL` and go-flags
  are R2's.
- `pkg/arch/arch_test.go`: the `exempt` comment on dbsender says it owns
  the queue table, no longer that gogo's interface takes an executor.

Mutation check: make dbsender's poller skip `realSender.Send` and watch
`pkg/mail/sender/dbsender` fail.

### G2

gogo's forms take no executor.

- Every form's `Validate(c *gin.Context) error` and `Save(c
  context.Context) (forms.FormSaveAction, error)`; `f.FormBase.Save(c)`.
- `gogoForms.DefaultHandler(c, form)` in the routes; the `db` variables
  that only fed it go.
- `DefaultHandler` no longer wraps `Save` in a transaction. Services own
  their transactions, so this is safe only if each `Save` makes at most
  one service call that writes. Check every form; if one makes two, stop
  and report it instead of changing it.
- `pkg/arch/arch_test.go`: drop `github.com/can3p/gogo/forms` from
  `callTargets` and the "until R3/R5" note; the test must still pass.
- `docs/architecture.md`, "Forms": `Save` calls a service and gets no
  executor; `Validate` keeps the field checks.

Mutation check: make one form's `Validate` accept an empty required field
and watch its form test fail.

### G3

pcom's error rendering and CSRF check move to gogo.

- `pkg/service/errors.go` keeps its doc comments and its names, as
  aliases of `apperr` (`ErrNotFound = apperr.ErrNotFound`, `type
  ValidationError = apperr.ValidationError`, `Invalid` calling
  `apperr.Invalid`), so no service changes.
- Delete `pkg/util/ginhelpers/render.go` and `render_test.go` (gogo has
  the tests now) and `pkg/util/ginhelpers/csrf/`. Importers use
  `github.com/can3p/gogo/util/ginhelpers` and `.../ginhelpers/csrf`.
  `pkg/util/ginhelpers/csp` stays.
- `router.go` installs `ginhelpers.Configure(ginhelpers.Options{
  RedirectToLogin: auth.RedirectToLogin, ShowErrors: !d.Config.InCluster})`
  on the engine before any route, and the CSRF groups use
  `csrf.CSRFMiddleware` with a function returning
  `auth.GetUserData(c).CSRFToken`.
- Unit tests that call a page builder or `ginhelpers` on a bare context
  get the same options from `pkg/testutil/ginctx.New`, so their
  assertions on error text don't change.
- `docs/architecture.md`, "Errors": the errors are gogo's `apperr`,
  re-exported by `pkg/service`; `ginhelpers` is gogo's, configured in
  `router.go`.

Mutation check: install `Configure` with `ShowErrors: true`
unconditionally, and watch the test that production hides error text
fail (if none fails, write it in `pkg/web/app`).
