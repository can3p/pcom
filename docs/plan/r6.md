### D1 alecthomas/assert → testify

Owns `pkg/util/url_test.go`, `pkg/markdown/modify_test.go`, `pkg/markdown/mdext/handle_test.go`,
`pkg/markdown/mdext/videoembed/videoembed_test.go`, `pkg/markdown/mdext/headershift/headershift_test.go`,
`pkg/markdown/mdext/blocktags/blocktags_test.go`, `pkg/postops/import_test.go`,
`pkg/forms/validation/fields_test.go`, `pkg/forms/validation/url_test.go`.

alecthomas/assert stops the test on the first failure (`t.Fatal`); testify's `assert` does not. Convert to
`github.com/stretchr/testify/require` so a failure still stops the test: `assert.Equal(t, want, got)` →
`require.Equal(t, want, got)` (same argument order), `Error`, `NoError` and `Contains` likewise. Keep every
assertion and message; don't edit `go.mod`. Done when `grep -rn alecthomas/assert --include=*.go .` is empty and
`make test-q PKG=./pkg/markdown/... ./pkg/util/... ./pkg/postops/... ./pkg/forms/...` passes.

### D2 pkg/errors → stdlib

Owns `pkg/auth/auth.go`, the three files under `pkg/feedops/reader/`, `pkg/forms/validation/` (the one
non-test file importing it), the three files under `pkg/mail/`, `pkg/media/upload.go`, `pkg/postops/` (the
one file), `pkg/service/posts/posts.go` (`grep -rln '"github.com/pkg/errors"' --include=*.go pkg` lists them;
`pkg/pgsession/store.go` is D4's).

Mapping: `errors.New` → stdlib `errors.New`; `errors.Errorf` → `fmt.Errorf`; `errors.Wrap(err, "msg")` →
`fmt.Errorf("msg: %w", err)`; `errors.Wrapf(err, "f %s", x)` → `fmt.Errorf("f %s: %w", x, err)`. The text
stays the same. **`Wrap(nil, …)` returns nil; `fmt.Errorf` never does.** Every `Wrap`/`Wrapf` whose error may
be nil needs an `if err != nil` first: `pkg/auth/auth.go:133` wraps `session.Save()` directly, and a blind
conversion fails every login. Keep `ErrMediaTooLarge`/`ErrUnsupportedMimeType` matchable with `errors.Is`
(`%w`). Don't edit `go.mod`. Done when the grep above lists only `pkg/pgsession/store.go` and
`make test-q PKG=./pkg/auth/... ./pkg/feedops/... ./pkg/forms/... ./pkg/mail/... ./pkg/media/... ./pkg/postops/... ./pkg/service/posts/...`
passes.

### D3 pgstore → pcom's own session store

Owns `pkg/pgsession/` (`store.go`, a new `cleanup.go` if needed, their tests), `pkg/web/app/router.go` (the
`NewStore` call and the session max age), a new migration, `pkg/config` for any new setting, and the
`web serve --help` golden.

Write a `gorilla/sessions.Store` over the existing `http_sessions` table (`id`, `key`, `data`, `created_on`,
`modified_on`, `expires_on`; indexes on `expires_on` and `key`) that keeps pgstore's wire format, so
sessions in production survive the deploy: the cookie is the securecookie-encoded session ID, `data` is the
securecookie-encoded `Values` with the same codecs, a missing row is a new session, `MaxAge < 0` deletes the
row. Queries go through `database/sql` (pgx driver), no `lib/pq`. The migration creates the table and
indexes `IF NOT EXISTS` (production already has them). `Regenerate` keeps its contract (old row deleted, new
ID on the next save) and its tests keep their assertions. Expired rows are deleted on a schedule (`pgstore.Cleanup` was never started): the
interval and the 30-day session age become settings (`AGENTS.md`, "No magic numbers"). Done when
`go list -deps ./cmd/web | grep -E 'pgstore|lib/pq'` is empty, `make test-q PKG=./pkg/pgsession/... ./pkg/web/... ./pkg/arch/...`
passes (with `./e2e/...`), and a test proves a cookie written by pgstore's encoding (fixed keys, fixed ID) is read back by the
new store.
