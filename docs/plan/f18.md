## F18 — Notes on an iPhone without the hand-built Shortcut

Status: planned · Depends on: — · Branch: `feat/f18-iphone-capture`

An iPhone user captures notes with pcom's own capture page saved to the Home Screen, and optionally a
Back Tap that opens it already recording. Nothing has to be built action by action, no API key is stored on
the phone, and nothing has to be signed or updated. The hand-built "pcom note" and "Quote from photo"
Shortcuts (`docs/guide/notes-on-a-phone.md`) and the material that exists only for them go.

Decided on 2026-11-22: no generated or signed Shortcuts (signing works only on Apple's side, so they could
carry nothing per user and had to be re-signed and re-shared on every change), no notes by email, and
nothing for the Action button, which the owner's iPhone SE 2 doesn't have.

### What already works

Nothing in this wave adds a capture feature; it is all in place for Android:

- `/controls/notes/new` is the capture page and the manifest's `start_url`; `header.html` has the
  `apple-touch-icon` and the manifest link, so Safari's **Add to Home Screen** gives it an icon.
- `?start=voice` starts a recording at once and `?start=photo` opens the camera; where the browser wants a
  tap first, the page shows one big "Tap to dictate" / "Tap to take a photo" (`begin` in
  `cmd/web/client/js/notes/capture.js`, `NoteCapture` in `pkg/web/pages_notes.go`).
- The recorder falls back to `audio/mp4`, which is what Safari records, and holds a screen wake lock while
  recording.
- A capture is kept on the phone and uploaded by the service worker with retries.

What iOS doesn't give a web app, and stays missing: receiving shares from other apps (WebKit bug 194593),
long-press shortcuts on the icon, and recording with the screen off or the phone locked.

### Behavior

- **On an iPhone**: in Safari, sign in, **Share → Add to Home Screen**. The icon opens the capture page, which
  records, takes photos and saves typed text.
- **Back Tap** (Settings → Accessibility → Touch → Back Tap, on every iPhone from the 8 and SE 2 on): a
  one-action Shortcut, **Open URLs** `https://<your pcom>/controls/notes/new?start=voice`, put on Double
  Tap. It opens Safari, not the Home Screen app: on iOS the two keep separate logins, so the user signs in
  in Safari as well. The same Shortcut works from Siri and as a Control Center control.
- **Quotes**: a passage from the Kindle app, or from a paper page through the camera's Live Text, is
  copied and pasted into the capture box (Q-F1 decides whether it is stored as a quote).
- **The API stays** for scripts and blg, and a notes key still opens only the notes routes; the docs stop
  calling it "the key for a phone Shortcut".
