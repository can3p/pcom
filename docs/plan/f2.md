## F2 — Comment editing (planned, #176)

A comment's author can edit it, at any time, and the rendered comment says
when it was last edited. No capabilities, no time limit, no edit history.

Decided by this plan (the issue leaves them open; Q18 in
`docs/open-questions.md` collects what the owner should confirm before the
wave starts):

- **Who:** the comment's author only, and only while they may still comment
  on the post (`postops.GetPostCapabilities(radius).CanLeaveComments`, the
  check `checkComment` already makes). Somebody who lost the connection
  can't open the post, so the edit link would be unreachable anyway. Anybody
  else gets `service.ErrNotFound`, as for a comment that isn't there.
- **Marker:** a new nullable column `post_comments.edited_at`, set only when
  the body actually changes (trimmed body differs). `updated_at` is not
  reused: it moves on any update, not only on edits. The marker reads
  "edited <renderHumanTime edited_at>" next to the comment's time, on the
  post page and in the feed's comment item. Mail is unchanged.
- **No notifications** on edit (Q18): authors and participants were told
  when the comment was left.
- **UI:** an "Edit" link on the author's own comments on the post page opens
  the comment form inline, prefilled, with the same controls (`mdeditor`,
  image upload), the way "Leave a comment" opens the reply form. Saving
  reloads the page (`forms.FormSaveFullReload`), as a new comment does. The
  feed has no edit link; editing happens on the post page.
- **Validation** is `posts.ValidateCommentBody`, the same as a new comment.

### C0

Owns a new migration `migrations/<timestamp>-post_comments_edited_at.sql`
(`alter table post_comments add edited_at timestamp`), the regenerated
`pkg/model/core` (`make generate`; never edited by hand),
`pkg/repo/comments.go`, `pkg/service/posts/comments.go`, a new
`pkg/service/posts/comments_edit_db_test.go` and
`pkg/testutil/factory/post.go` (only if a comment factory option is
missing).

`posts.EditComment(ctx, actor, commentID, body string) error`: validates
the body (`service.Invalid("body", …)`), then in one transaction loads the
comment (`repo.CommentByID`), returns `ErrNotFound` unless
`comment.UserID == actor.ID`, re-runs the comment check on its post, and
stores the trimmed body with `edited_at = now()` when it differs (a new
`repo.UpdateCommentBody`; nothing is written when it is the same). A table
test: the author edits (body and `edited_at` stored); the same body leaves
`edited_at` null; another user, the post's author, an anonymous actor and a
missing id are refused; an author who lost the connection is refused; an
invalid body is `service.Invalid`; no mail is queued.
